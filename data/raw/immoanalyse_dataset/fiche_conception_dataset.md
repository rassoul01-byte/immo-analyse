# Fiche de conception du dataset

## Volumes
- plateforme : 875 lignes
- agence : 680 lignes
- particuliers : 731 enregistrements
- notaires : 410 lignes
- historique : 528 lignes
- **Total brut : 3224 lignes**

## Problèmes représentés
- 5 schémas différents, 5 niveaux de qualité.
- Ventes et locations, 7 types de biens.
- Valeurs manquantes, formats hétérogènes, incohérences, doublons, atypiques.
- Cas ambigus documentés dans le fichier formateur.

## Limites
- Coordonnées synthétiques autour des centres-villes.
- Prix inspirés de tendances générales, non officiels.
- Volumétrie modérée pour 13 étudiants.
